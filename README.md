# Presente de Natal — site responsivo

## Arquivos
- `index.html`: estrutura do site
- `style.css`: visual para celular e computador
- `script.js`: simulador, tabela e envio de simulação ao WhatsApp

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`, depois salve.
6. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

Também pode conectar o repositório ao Render como **Static Site** e usar a raiz do projeto como diretório de publicação.

## Atenção sobre as informações financeiras
O site usa a redução de 50% apenas como cálculo promocional informado pelo operador do site. Não significa que a administradora aprovou a condição, que o crédito foi contemplado ou que o valor total do consórcio caiu pela metade. Confirme e documente as condições reais antes de divulgar a oferta. Os nomes das administradoras aparecem apenas como referências e não indicam parceria ou autorização.
